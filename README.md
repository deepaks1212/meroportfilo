# Portfolio Project

This repository now contains two separate projects:

- `frontend/` — React frontend built with Vite
- `backend/` — Node.js + Express backend for the contact API

## Setup

### Backend
1. `cd backend`
2. `npm install`
3. `npm run dev` or `npm start`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Notes

- The backend API runs on `http://localhost:5000` by default.
- The frontend runs on `http://localhost:5173` by default.
- Keep `backend/.env` private and do not commit it.
